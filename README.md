# Python·Git 콘솔 퀴즈 게임

## 프로젝트 개요
Python 3.10 이상에서 실행되는 콘솔 퀴즈 게임입니다. 퀴즈 풀기, 추가, 목록, 최고 점수 확인을 지원하며 JSON 파일에 데이터를 저장합니다.

## 퀴즈 주제와 선정 이유
Python 기초 문법과 Git 명령어를 선택했습니다. 미션 수행에 필요한 기본 개념을 직접 퀴즈로 복습하기 위해서입니다.

## 실행 방법
1. Python 3.10 이상을 설치합니다.
2. 프로젝트 폴더의 터미널에서 `python main.py`를 실행합니다. (Windows에서 `py main.py`도 가능)
3. 화면 메뉴에서 1~5를 선택합니다.

추가 패키지는 필요하지 않습니다.

## 기능 목록
- 퀴즈 풀기 및 결과 출력
- 퀴즈 추가, 퀴즈 목록 출력
- 최고 점수 확인 및 갱신
- 숫자/빈 입력 검증, Ctrl+C/EOF 안전 종료
- JSON 데이터 불러오기/저장 및 손상 파일 초기화

## 파일 구조
```text
python_quiz_game/
├── main.py       # 실행 파일과 두 클래스 Quiz, QuizGame
├── state.json    # 실행 시 생성되는 저장 데이터
├── README.md     # 프로젝트 설명
└── .gitignore    # Git 제외 규칙
```

## 데이터 파일 설명
`state.json`은 `main.py`와 같은 프로젝트 루트에 UTF-8로 저장됩니다. `quizzes`는 문제 객체의 목록이고, `best_score`는 최고 정답 개수(게임 미실행 시 `null`)입니다.

```json
{
  "quizzes": [
    {
      "question": "예시 문제",
      "choices": ["보기1", "보기2", "보기3", "보기4"],
      "answer": 2
    }
  ],
  "best_score": null
}
```

첫 실행에 파일이 없으면 기본 문제 5개를 생성합니다. 손상된 파일은 기본 데이터로 초기화되므로 중요한 데이터는 백업하세요.

## Git 수행 기록
이 프로젝트를 제출하기 전에 직접 10개 이상의 의미 있는 커밋, 별도 브랜치 생성과 병합, `clone`과 `pull` 실습을 수행하고 `git log` 등으로 확인해야 합니다. 이 파일에는 완료하지 않은 실습을 완료한 것으로 표시하지 않습니다.

## 프로그램 테스트 방법

1. 프로그램을 실행한다.
2. 메뉴에서 1번을 선택해 퀴즈를 푼다.
3. 정답과 오답 안내가 정상 출력되는지 확인한다.
4. 메뉴에서 2번을 선택해 새 퀴즈를 추가한다.
5. 메뉴에서 3번을 선택해 추가한 문제를 확인한다.
6. 최고 점수를 확인한다.
7. 프로그램을 종료하고 다시 실행한다.
8. 추가한 퀴즈와 최고 점수가 유지되는지 확인한다.

## 프로그램 클래스 구조

### Quiz 클래스
개별 퀴즈 문제를 관리하는 클래스입니다.

- question: 문제 내용
- choices: 4개의 선택지
- answer: 정답 번호
- show(): 문제와 선택지를 출력
- is_correct(): 사용자 정답 확인

### QuizGame 클래스
전체 퀴즈 게임을 관리하는 클래스입니다.

- quizzes: 등록된 퀴즈 목록
- best_score: 최고 점수
- play(): 퀴즈 게임 진행
- add_quiz(): 새로운 문제 등록
- show_quizzes(): 문제 목록 출력
- save_state(): JSON 파일에 데이터 저장

두 클래스를 분리하여 개별 문제 관리와 게임 운영의 역할을 구분했습니다.
